## 每日最冷 10 个地方

除「最冷冠军」外，每天还会更新 [TOP10.md](TOP10.md)：

- 全体候选点按**当前温度**升序的前 10 个地方，逐个列出当前温度（单位 °C）、坐标、所在区域、是站点还是网格点；
- 另一张「具名地点最冷 10 地」表，只列有正式地名的站点，方便看清具体是哪里；
- 结构化版本 `data/top10.json`，每个条目含 `current_temp_c` 与 `unit` 字段。

这里的「当前温度」是数据时刻的近地面 2 米气温模式值，不是体感温度，也不是气象站实测值。

## 运行时间

- 定时：`30 0 * * *`（UTC 00:30 = 北京时间 08:30）。GitHub Actions 的定时任务普遍有延迟，实际执行时间可能晚几十分钟到数小时。
- 随时手动：仓库 → Actions → **每日查询世界最冷的地方** → Run workflow。
- 注意：GitHub 会停用连续 60 天无任何仓库活动的定时工作流，长期挂着偶尔手动跑一次即可。

## 数据口径（重要）

- 数据源：**Open-Meteo** `/v1/forecast` 的 `current=temperature_2m`，免费、无需 API Key，单位 **°C**，是 ECMWF/GFS 模式的近地面 2 米气温分析/预报值。
- 候选点：27 个具名极寒站点（南极各站、格陵兰 Summit、奥伊米亚康、上扬斯克、加拿大北极群岛、阿拉斯加、漠河等）+ 南极高原 48 个网格点 + 格陵兰内陆 4 个网格点，共 **79 个**。
- 「今日最冷」= 这批候选点里的最低值，**是全球采样最小值，不是全球连续温度场的数学最小值，也不是气象站实测记录**。
- 参考常量：地球有观测记录以来的最低气温是南极沃斯托克站 **−89.2 °C**（1983-07-21）。
- 显示时间统一为**北京时间（UTC+8）**；接口返回的时刻是 UTC。
- 失败策略：接口请求失败会重试 3 次，有效点不足 60% 或全部为空时直接让本次运行失败，**绝不把「读失败」当成「读到空」去生成错误结论**。
